# Kanji Bridge (app edition)

The hosted web-app edition of [Kanji Bridge](https://github.com/hanjejeme2023-oss/kanji-bridge) (漢字ブリッジ), a study tool for people who know Japanese and Korean and are learning Chinese and Vietnamese through shared Sino-vocabulary. This repository turns the finished static app into a site with an overview page, an English, Japanese and Korean interface, and optional Google sign-in that syncs study progress across devices. Without an account, the app works as before and keeps progress in the browser. The code is MIT ([`LICENSE`](LICENSE)). The dictionary data is imported from kanji-bridge and stays CC BY-SA 4.0 ([`public/app/DATA-LICENSE.md`](public/app/DATA-LICENSE.md)).
